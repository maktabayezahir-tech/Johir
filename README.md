# মাকতাবায়ে জহির

**বই বিক্রয়, স্টক ও হিসাব ব্যবস্থাপনা অ্যাপ**

</div>

বই বিক্রি, রশিদ প্রিন্ট, স্টক, কাস্টমার ও বিক্রয় রিপোর্ট এক জায়গায় সামলানোর একটি সহজ ওয়েব অ্যাপ। কোনো সার্ভার বা ডাটাবেস লাগে না।

## সুবিধাসমূহ

- 🛒 দ্রুত বই খুঁজে বিক্রয় তালিকায় যোগ, ছাড় (%) ও প্যাকেট খরচ
- 🧾 ক্রমিক নম্বরসহ ক্যাশ মেমু ও রশিদ প্রিন্ট
- 📦 বই ও স্টক ব্যবস্থাপনা (যোগ, এডিট, মোছা, স্টক পরিবর্তন)
- 👥 কাস্টমার তালিকা
- 📊 বিক্রয় রিপোর্ট (PDF ও CSV)
- 💾 ব্যাকআপ ও রিস্টোর (বই, বিক্রয়, কাস্টমার)
- 📱 মোবাইলে অ্যাপের মতো ইনস্টল করা যায় এবং ইন্টারনেট ছাড়াও চলে

## GitHub Pages-এ প্রকাশের নিয়ম

1. GitHub-এ নতুন repository বানান, যেমন `maktabaye-zahir`। (ফ্রি অ্যাকাউন্টে GitHub Pages-এর জন্য repository **Public** হতে হয়।)
2. এই ফোল্ডারের **সব ফাইল ও `icons` ফোল্ডার** repository-তে আপলোড করুন (`Add file → Upload files`)।
3. **Settings → Pages** এ যান।
4. **Source:** `Deploy from a branch` নির্বাচন করুন, **Branch:** `main` এবং ফোল্ডার `/ (root)` দিয়ে **Save** করুন।
5. ১–২ মিনিট পর অ্যাপ চালু হবে এই ঠিকানায়: `https://আপনার-ইউজারনেম.github.io/maktabaye-zahir/`

## মোবাইলে ইনস্টল

- **Android (Chrome):** মেনু (⋮) → *Install app* / *Add to Home screen*
- **iPhone (Safari):** Share → *Add to Home Screen*

## ⚠️ ডেটা সম্পর্কে জরুরি কথা

- সব ডেটা **ব্যবহারকারীর নিজের ব্রাউজারে (localStorage)** জমা থাকে। GitHub বা অন্য কোথাও যায় না।
- তাই এক ফোনের ডেটা অন্য ফোনে বা কম্পিউটারে দেখা যাবে না।
- ব্রাউজারের ডেটা (cache/site data) মুছলে হিসাবও মুছে যায়।
- নিয়মিত **⬇ ব্যাকআপ** নিন এবং ফাইলটি নিরাপদ জায়গায় রাখুন। নতুন ডিভাইসে বা ডেটা হারালে **⬆ রিস্টোর** দিয়ে ফিরিয়ে আনুন।

## ফাইল কাঠামো

```
index.html       অ্যাপ (HTML, CSS ও JavaScript একসাথে)
manifest.json    মোবাইলে ইনস্টলের তথ্য
sw.js            অফলাইন সাপোর্ট
favicon.ico      ব্রাউজার আইকন
icons/           লোগো ও অ্যাপ আইকন
.nojekyll        GitHub Pages-এর জন্য
```

## আপডেট করার পর

`index.html` বা অন্য ফাইল বদলালে `sw.js` ফাইলের শুরুতে `CACHE` এর সংস্করণ নম্বর বাড়িয়ে দিন (`v1` → `v2`), যাতে ব্যবহারকারীরা নতুন সংস্করণ পায়।

## দোকানের তথ্য বদলানো

রশিদে ছাপা ঠিকানা `index.html` ফাইলে `makeReceipt` ফাংশনের ভেতরে আছে। সেখানে লেখা ঠিকানাটি বদলে নিন।
